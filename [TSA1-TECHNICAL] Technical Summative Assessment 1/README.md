Source Code (BookBridgeApp.java): the human-readable Java code written in the IDE (like Netbeans).

Compiler (javac - part of JDK): Converts .java source code into .class bytecode, checking for syntax errors.

Bytecode (BookBridgeApp.class): Platform-neutral instructions intended for execution by Java's virtual machine.

JVM (Java Virtual Machine - part of JRE): Reads bytecode, interprets/JIT-compiles it to native machine code, and executes it on your operating system.

Output: The running console application interaction.

JDK Contribution: Provides the development tools (javac compiler, debugger, standard libraries) necessary to compile and analyze Java code.
